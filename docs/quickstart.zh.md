# 快速开始

本指南帮助您快速启动 Clawland-AI。

## 环境要求

- Node.js >= 14
- npm >= 6

## 安装步骤

1. 克隆仓库：

   ```bash
   git clone https://github.com/Clawland-AI/clawland-ai.github.io.git
   ```

2. 进入目录并安装依赖：

   ```bash
   cd clawland-ai.github.io
   npm install
   ```

3. 启动开发服务器：

   ```bash
   npm run dev
   ```

4. 打开浏览器访问 `http://localhost:3000`。

## 常见问题

- 如遇到依赖安装失败，请检查 Node.js 和 npm 版本。
- 如需帮助，请参考 [贡献指南](../CONTRIBUTING.zh.md)。

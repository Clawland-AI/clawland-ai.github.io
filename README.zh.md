# Clawland-AI

Clawland-AI 是一个用于 PicClaw、NanoClaw、MicroClaw、MoltClaw 和 Clawland Fleet 的开源 AI 技能平台。

## 快速开始

1. 克隆仓库：

   ```bash
   git clone https://github.com/Clawland-AI/clawland-ai.github.io.git
   ```

2. 安装依赖：

   ```bash
   cd clawland-ai.github.io
   npm install
   ```

3. 启动本地开发服务器：

   ```bash
   npm run dev
   ```

4. 打开浏览器访问 `http://localhost:3000`。

## 主要组件

- **PicClaw**：图像识别与处理模块。
- **NanoClaw**：轻量级推理引擎。
- **MicroClaw**：微型设备集成。
- **MoltClaw**：模型训练与部署。
- **Clawland Fleet**：设备管理与编排。

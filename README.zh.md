# Clawland 文档站

本仓库存放 [clawland-ai.github.io](https://clawland-ai.github.io) 的源文件，也就是 Clawland 项目的文档网站。

网站由 [Jekyll](https://jekyllrb.com/) 构建，托管在 [GitHub Pages](https://pages.github.com/) 上。

## 本地开发

```bash
gem install bundler jekyll
bundle install
bundle exec jekyll serve
```

然后访问 http://localhost:4000
